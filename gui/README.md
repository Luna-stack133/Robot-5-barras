# App de escritorio R5B Lab

`R5B_Lab/` es la app de escritorio del robot (Python 3 + PySide6), versión **0.4.1**. Reemplaza a la GUI de Tkinter del inicio del proyecto (queda en el historial de git).

```bash
cd gui/R5B_Lab
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Pantallas, comandos y novedades de cada versión: [R5B_Lab/README.md](R5B_Lab/README.md). Funciona con el firmware 1.3 y el 1.4; sin puerto abierto trabaja en simulación.
